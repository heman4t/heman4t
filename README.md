## Selected projects

### Vedic Astrology · Source-grounded AI

*Independent product · 2026–present*

**Traceable interpretations:** an engine that connects generated astrological interpretations to a curated collection of classical texts.

**My work:** Python APIs, a **100+ tool MCP server**, local semantic retrieval and evaluation workflows that check source fidelity and actual tool use. The evaluations test grounding and software behaviour, not predictive accuracy.

**Built with:** Python · FastAPI · PostgreSQL · MCP · Ollama<br>
[Architecture and companion evaluation work →](PROJECTS.md#independent-products-and-earlier-engineering)

### HariDream · AI-enabled lending operations

*Client project · 2025–2026*

**Connected lending workflows:** a platform bringing applicant data, customer conversations and document processing into everyday ERP operations.

**My work:** ERP integrations, contextual AI replies over WhatsApp, KYC document data extraction, Meta audience synchronisation and an ERP MCP interface, with role-scoped access to Elasticsearch-backed data.

**Built with:** Frappe / ERPNext · Python · OpenAI · Elasticsearch · Meta APIs<br>
[Applications, integrations and contribution details →](PROJECTS.md#haridream)

### AVS Holidays · Self-hosted speech analytics

*Client project · 2025*

**Call insights from recordings:** services that turn multi-channel audio into transcripts, summaries, sentiment analysis and suggested follow-ups.

**My work:** Speech inference, voice-activity detection, backend services and containerised GPU deployment. My primary contribution was the AI pipeline, alongside contributions to the companion web application.

**Built with:** FastAPI · PyTorch · NVIDIA Canary-1B · silero-vad · Redis · Docker<br>
[Pipeline components and contribution details →](PROJECTS.md#avs-holidays)
