## What I'm building

**Source-bound AI engine** · Independent product, 2026–present<br>
A Vedic-astrology prediction engine where claims must trace to held classical texts. A **100+ tool MCP server**, offline semantic retrieval and **34 deterministic evaluation cases** check source fidelity and actual tool use. Built with Python, FastAPI, PostgreSQL and Ollama; supported by an 11k+ test suite.

**HariDream · AI inside ERPNext**<br>
A lending platform connecting **OpenAI, WhatsApp Cloud API and Meta Marketing API** to ERP workflows. I built contextual AI replies, Vision-based KYC extraction, hashed-identifier audience sync and an ERP MCP integration, with role-scoped access to Elasticsearch-backed applicant data.

## AVS Holidays · Self-hosted speech analytics

**My focus: inference and the AI services behind call analysis (2025).**

Built services that turn recorded, multi-channel customer calls into transcripts and useful follow-up information:

**Call recordings → voice detection & transcription → summaries, sentiment, toxicity flags & next steps**

NVIDIA **Canary-1B** and **silero-vad** handle speech processing; **FastAPI + Redis** coordinate jobs, with GPU inference deployed through **Docker Compose**. My work focused on the inference pipeline and AI backend.
